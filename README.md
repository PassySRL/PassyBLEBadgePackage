# PassyBLEBadgePackage

Binary Swift package for the Passy Apple SDK. Requires iOS 17 and Mac Catalyst 17 or later.

Add https://github.com/PassySRL/PassyBLEBadgePackage.git to Xcode and select the product declared in Package.swift.
Release 0.0.2 contains the XCFramework files attached to the matching GitHub Release.
